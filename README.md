# AEGIS Data/Quality Analyst

Personal-fleet Data/Quality specialist for Hamid. Reviews other agents' published reports for drift and schema bugs; flags to `aegis-ceo`. Advisory only.

## Skills

| Skill | Purpose |
|-------|---------|
| `/review-fleet-outputs` | Periodic/on-demand consistency + schema review of recent fleet reports |
| `/flag-data-drift` | Escalate a concrete finding to `aegis-ceo` (confirmed delivery only) |
| `/trial-review` | One-time initial real review before enabling a schedule |
| `/onboarding` | Setup checklist |
| `/update-dashboard` | Refresh `dashboard.yaml` |
| `/reconcile-docs` | Doc/skill coherence |

## Tier

Free-pool via OmniRoute (`gemini/gemini-3.7-flash`), owned by `aegis-infra`. Cross-branch asks go through `aegis-ceo` — see [aegis-infra A2A routing](https://github.com/hamidmatiny/aegis-infra/blob/main/docs/a2a-routing.md).
